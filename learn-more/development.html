Cape Development.

Join the Development Team!

Cape is a Minecraft mod developed by Ennismore0. Our goal is to bring Cape to more Minecraft versions and make it available to more players.

I'm focusing on developing the main version of Cape. I'm looking for volunteer developers who can help port the mod to other Minecraft versions.

What Is Version Porting?

Minecraft updates can change the code and systems that mods rely on. Porting means adapting a mod so it can work with a different Minecraft version.

As a developer on the Cape team, you could help update code, resolve compatibility issues, test changes, and maintain a port for your assigned version.

Areas of Contribution

Version Porting

Adapt Cape to Minecraft versions other than the main version.

Testing

Test changes, identify bugs, and verify that a version port works as expected.

Bug Fixes

Investigate problems and help improve compatibility and stability.

Who Can Apply?

We're looking for people who are interested in Minecraft mod development, can communicate with the team, and are willing to learn and collaborate.

Experience with Java, Fabric, and the relevant Minecraft version is helpful for version-porting work.

Volunteer Project

Cape's development team is volunteer-based. This is an unpaid opportunity to contribute to an open-source Minecraft mod and gain development experience.

How to Get Started
  1. Visit the Cape repository on GitHub.
  2. Explore the source code and project structure.
  3. Read the project's license and contribution instructions before submitting changes.
  4. Get in touch through the project's available communication channels to discuss contributing.
